# Code of conduct

Be respectful and constructive in issues, pull requests and reviews.

- Discuss the code and the evidence, not the person.
- No harassment, insults, discrimination or unwelcome personal attention.
- Do not post other people's private information, real customer data or
  credentials.

The repository owner may edit or remove comments, close threads and block
participants who do not follow these rules. Report conduct problems privately
to the repository owner through their GitHub profile.
